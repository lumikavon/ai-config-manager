# UI 原型与验收

先完成原型再实现。左侧导航：配置、历史记录、设置；窄屏改为顶部。中文默认、英文切换，全部应用文案集中管理。
配置表单含 URL、密码型 API Key、模型、默认加密开关。已保存密钥不回传、不回填，空白保留。明文切换需风险确认，未保存离开/取消/重载需确认。展示加载、空、错误、保存、成功和解密失败状态。
历史展示时间、来源、脱敏差异、SHA-256 摘要，支持刷新及空状态。设置含静默启动、关闭到托盘、开机启动、语言及版本平台。开机启动显示系统实际结果，失败不伪造成功。浏览器缺少 Tauri 时明确不支持，不提供假数据。
验收：键盘焦点、标签和 aria-live 可用；窄窗口不横向溢出；保存携带 expected_revision；密钥保存后清空，永不日志输出；单测覆盖明文确认、未保存保护、密钥保留、后端失败；生产构建成功。
